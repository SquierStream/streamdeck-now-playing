# Contributing

This repository is documentation and a feedback hub for **Now Playing for Dials** — a commercial, closed-source plugin. There's no source code here to submit pull requests against.

The useful way to contribute is through **[GitHub Discussions](../../discussions)**:

- **Ideas** — a new skin, a setting you're missing, a workflow you want supported.
- **Q&A** — installation trouble or anything you're stuck on.
- **Show and tell** — your own setup, screenshots, skin concepts.

Documentation fixes (typos, unclear steps, missing settings) are welcome as pull requests against the README and files in `docs/`.
